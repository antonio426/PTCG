# ROADMAP — 對照目標網站的功能路線圖

> 目標網站：`https://www.ptcg-tw-sim.com`（本專案想做成的樣子）。
> 本文件由 2026-08-15 的實機盤點產生：以 Playwright 實際操作目標網站全部頁面
> （首頁/卡牌資料庫/牌組編輯器/牌組公布欄/對戰演練/錦標賽/對戰內設定面板）與本專案全部頁面，
> 逐項比對得出，另有 220 場參考站對局語料佐證（`server/src/scripts/audit-vs-reference.ts`）。
> 完成一項就把該項打勾並註記 commit；新增差距時附上實測證據。

## 模組現況對照

| 模組 | 目標網站 | 本專案 |
|---|---|---|
| 卡牌資料庫 | 依卡包分組（H/I/J 分區、發售日、張數）＋招式/特性文字搜尋 | 平面清單＋類型/屬性/系列篩選 |
| 牌組編輯器 | 多維搜尋＋標籤＋匯入匯出（文字/圖片/官網代碼/JSON）＋Email 同步 | 基本搜尋＋localStorage＋60/4 驗證 |
| 對戰演練 | 本機雙人＋vs AI＋線上連線；擲幣選先攻、mulligan 互動、悔棋、BGM、縮放 | 僅 vs AI（AI 三難度＋ClaudeAI，此點領先） |
| 牌組公布欄 | 投稿/讚/收藏/留言/一鍵匯入/賽事名次篩選 | 無 |
| 錦標賽 | 瑞士制/淘汰制、email 帳號限定 | 無 |
| 帳號系統 | 匿名 + Email 註冊（跨裝置同步） | 無 |
| 本專案獨有 | — | AI 實驗室、ClaudeAI 困難模式、效果覆蓋稽核工具鏈 |

## Phase 1 對戰核心 parity 【✅ 完成 2026-08-15：ed3d5f7 / 5fbcfd3 / fd06370 / 上述 rematch commit】

1. ✅ 擲硬幣決定先後 + 獲勝者「選擇」先攻/後攻
2. ✅ Mulligan 互動：選擇補抽 0~N 張、補抽基礎可直接上備戰（AI 側維持自動補滿）
3. ✅ 悔棋（undo）— 快照制、回捲含 AI 回合
4. ✅ 重新開局（頂欄＋終局畫面）

## Phase 2 牌組編輯器＋卡牌資料庫強化

- 招式關鍵字搜尋、特性關鍵字搜尋（資料已齊，純前端篩選）
- 進化鏈搜尋（重用 `server/src/game/evolutionChains.ts` 種族鏈表）
- 標籤篩選：ACE SPEC / 古代 / 未來 / 太晶 / 超級進化 / 訓練家冠名（subtypes 已有）
- 賽季 H/I/J 標篩選（`regulationMark` 已回填）
- ⭐ 常用卡收藏
- 匯出/匯入：文字、官網 deck code（需研究官方格式）、JSON；圖片匯出後期
- 合法性補完：「至少 1 隻基礎寶可夢」（`validateDeck` 目前只查 60 張/同名 4 張）
- 未存檔草稿標示、內建預組唯讀瀏覽入口
- 資料庫頁依卡包分組視圖（資料在 `sets.json`）

## Phase 3 本機雙人對戰（同機輪流）

- 引擎本就雙人：`setup()` 的 `interactivePlayer` 擴為兩側即可
- 主要工作在 UI：換手遮蔽畫面、雙視角切換、雙方都走 `choose_active` 流程

## Phase 4 對戰體驗

- 拖曳操作（手牌→戰鬥場/備戰、拖曳附能；點擊式保留）
- BGM / 遊戲音效 + 設定面板開關
- 畫面縮放/解析度模式（60%~100% + 自動，小螢幕支援）
- 全螢幕按鈕
- 對手 mulligan 完整手牌揭示 UI（Phase 1 先以 log 呈現）

## Phase 5 帳號 + 線上對戰

- Email 帳號（SQLite 起步）＋牌組跨裝置同步
- **現成資產**：boardgame.io `Server` 已在 `server/src/index.ts` 註冊、`PtcgGame.ts` 已存在，
  **只是 client 從未接上**——接 `boardgame.io/react` client 即可起步，不必從零寫連線層

## Phase 6 牌組公布欄

- 投稿/讚/收藏/留言/一鍵匯入/賽事名次標記（依賴 Phase 5 的帳號＋DB）

## Phase 7 錦標賽

- 瑞士制/淘汰制、配對、即時對戰（依賴 Phase 5+6）

## 已具備、無需重做

回合/總計時器、對戰紀錄匯出（txt/json）、雙方棄牌堆檢視、hover 卡片預覽、i 詳情
（含場上狀態 HP）、終局 Modal、mulligan 自動流程（Phase 1 升級為互動）、預組 56 副、
AI 難度三級、AI 實驗室。
